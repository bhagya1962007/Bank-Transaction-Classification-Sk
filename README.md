# Bank Transaction Classification using Scikit-learn

This project classifies bank transactions into categories such as groceries, bills, shopping, travel, salary, and entertainment.

## Run
1. Install dependencies:
   pip install -r requirements.txt
2. Train the model:
   python train_model.py
3. Classify a new transaction:
   python predict.py

The included dataset is synthetic and stored in `data/bank_transactions.csv`.
